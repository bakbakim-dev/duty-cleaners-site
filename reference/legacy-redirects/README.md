# Legacy redirect maps for other platforms

These three files translate the legacy WordPress URL map for Apache, nginx and
Vercel. They are kept only as a reference for a possible future platform move.

They used to live in `site/public/`, which meant they were deployed and served
as crawlable plaintext at `dutycleaners.ca/legacy-redirects.htaccess` and the
like — publishing the site's entire URL map, for three platforms it does not run
on. Nothing generates them and nothing reads them, so they moved here, outside
the published directory.

The live redirect rules are `site/public/_redirects`, which is generated by
`bun run prebuild` from `src/data/legacy-urls.ts`. That file is the source of
truth. If one of these ever needs regenerating, regenerate it from there rather
than hand-editing it.
